# 📦 SmartBox - Recebedor Inteligente

O **SmartBox** é um ecossistema de hardware e software projetado para o recebimento seguro e autônomo de encomendas. Através do site administrativo, o usuário gera um código de acesso temporário e o envia ao entregador, que realiza o desbloqueio digitando a senha em um teclado numérico integrado à caixa.

---

## 🚀 Funcionalidades

* 🔑 **Geração de Senhas Únicas:** Criação de códigos PIN temporários via painel web.
* ⌨️ **Acesso Físico por Teclado:** Abertura local simples e rápida para o entregador digitando a senha.
* 📜 **Registro de Eventos:** Log detalhado de qual senha foi utilizada, com data e horário do recebimento.
* 🔔 **Notificação Instantânea:** Alerta ao usuário assim que a caixa é aberta pelo entregador.
* 🛡️ **Sensores de Confirmação:** Verificação automática do fechamento da porta e validação de pacotes depositados.
